# 📱 Aya Phones

Aya Phones is a website for an electronics store where users can explore different products, including smartphones, tablets, and computers.

## ✨ Features
- 📱 Browse smartphones
- 📲 Explore tablets
- 💻 Discover computers
- 🛒 Select products
- 💳 Order form with cash on delivery
- 🧾 Order confirmation page
- 🎨 Responsive and user-friendly interface
- 🌙 Dark mode

## 🛠️ Technologies Used
- HTML5
- CSS3
- PHP
- Font Awesome
- XAMPP (local development)

## 🚀 Installation
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache from the XAMPP Control Panel.
4. Open your browser and visit `http://localhost/AyaPhones/`.
